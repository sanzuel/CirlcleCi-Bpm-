# SongSetlist - CircleCI Build

A clean starter Android project for the SongSetlist app.

## Build
CircleCI uses `.circleci/config.yml` to build:

`app/build/outputs/apk/debug/app-debug.apk`

This version includes:
- Song library
- BPM values
- Fast search/filter
- Dark interface
- Android APK build configuration for CircleCI

This is a fresh CircleCI test project, separate from the previous Codemagic ZIP.
